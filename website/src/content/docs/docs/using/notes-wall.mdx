The Notes Wall holds the measurements, schedules, instructions and links that never quite fit a
checklist. Notes are color-coded, can be pinned to the top, and are shared with everyone in the
house.

<Aside type="note">
	The Notes Wall works the same on the web and in the [app](/docs/getting-started/pairing) — the same
	notes, synced.
</Aside>

![The Notes Wall in the Pantry web app — color-coded notes for measurements, schedules and household info.](/docs/notes-wall.png)

## Create a note

<Tabs syncKey="platform">
	<TabItem label="Web">
		<Steps>

		1. Open the **Notes Wall**.

		2. Select **New note**.

		3. Give it a title and content — Markdown, so headings, lists, links and task lists all work.

		</Steps>
	</TabItem>
	<TabItem label="Mobile & desktop">
		<Steps>

		1. Open the **Notes Wall** tab.

		2. Tap the add button.

		3. Give it a title and content — Markdown, so headings, lists, links and task lists all work.

		</Steps>
	</TabItem>

## Task lists

A note written with Markdown task lines (`- [ ] Rinse the filter`) renders them as checkboxes you
can tick straight from the note — no need to open the editor. A tick is saved back into the note's
text, so everyone in the house sees it.

## Color and pin

- **Color** a note (or leave it the default) to tell notes apart at a glance — the same palette the
  app uses.
- **Pin** a note to keep it at the top of the wall, above the rest.
- **Reorder** notes to arrange the wall the way the house thinks about them.

## Turn a note into a list

A note that has grown into a shopping or to-do list can be imported straight into a checklist with
**Import to list** — pick the destination list and Pantry turns the note's lines into items.

## Sync a note with a file

A note can be tied to a Markdown file in your Nextcloud Files. Edit the note in Pantry and the file
changes; edit the file — in the Files app, in [Notes](https://apps.nextcloud.com/apps/notes), on a
synced desktop folder — and the note changes. Each edit is carried across as it is saved, so the two
never sit out of step waiting for a sync to run.

This is how you keep a note where the rest of your writing lives, or bring writing you already have
onto the wall.

### Start from a note

<Steps>

1. Open the note's menu and select **Sync to file …**.

2. Pick the folder to keep the file in.

</Steps>

Pantry creates the file there, named after the note, and holds the two together from then on. The
file is created in your own Files — housemates editing the note write through to it, wherever it
lives.

### Start from a file

<Steps>

1. On the Notes Wall, select **Import from file …**.

2. Pick a Markdown or text file.

</Steps>

The file becomes a note on the wall, titled after the filename, and the two stay tied together.

### The filename is the title

A synced note's title and its filename are the same thing, which is what lets Notes show a synced
note as one of its own. Rename the note and the file is renamed; rename the file and the note takes
the new name.

Filenames cannot hold every character a title can, so a title like `Trip: 2026/07` becomes the file
`Trip_ 2026_07.md` — and the note takes that spelling too, to keep the two in agreement.

### Where it shows

A synced note carries the path of its file at the bottom of the card, so you can tell at a glance
which notes are tied to a file and which stand alone.

Moving the file in Files does not break anything — the note follows it, and the path on the card
updates. If the file is in the trash, the card says its file is missing; restoring the file picks
the sync back up.

### Stop syncing

Select **Stop syncing** on the note. The note keeps its content, the file keeps its content, and
neither one sees the other's edits again.

<Aside type="note">
	Setting a sync up and stopping one is done in the web app.
</Aside>

## Trash

Moving a note to the trash soft-deletes it. Trashed notes can be restored, or permanently deleted,
from the trash view.

<Aside type="caution">
	Permanently deleting a note, or emptying the notes trash, cannot be undone.
</Aside>
